# Bounded scientific-figure observation checker

`scripts/figure_quality/figure_quality_check.py` is a read-only diagnostic for manually or source-verified semantic observations. It is not an image recognizer, a source editor, a figure quality score, or a native-application test. Supply the actual source and candidate files whose observations were measured. Both SHA-256 values are checked against those files on every run.

Use it only after source inventory and measurement. Its findings support the measured gate in [quality-specification.md](quality-specification.md); they cannot replace the separate source-fidelity, visual or application checks. For reusable synthetic regression cases and independent task evaluations, read [figure-quality-fixtures.md](figure-quality-fixtures.md).

## Run

```sh
python scripts/figure_quality/figure_quality_check.py observations.json --source intact-source.svg --candidate candidate.svg --output new-report.json
python -m unittest discover -s scripts/figure_quality -p "test_*.py" -v
python -O -m unittest discover -s scripts/figure_quality -p "test_*.py" -v
```

Run these commands from the skill root. The source/candidate can be SVG, PPTX, PNG, or other actual artifacts: this tool hashes them, but does not parse their scientific contents. Do not imply that hashing a PPTX verifies data, OLE, or native editability. A scene or test manifest is not a substitute for the actual artifact file in a real task.

The CLI prints diagnostic JSON, including observations, evidence references, methods, thresholds, limitations, and counts by status. It refuses existing output paths or input aliases, and never mutates source, candidate, or observations.

- Exit **0**: the supplied checks passed or were explicitly nonapplicable/exempt. This is not complete figure acceptance.
- Exit **1**: at least one measured requirement failed. Protected scientific failures are marked `protected_fidelity: true`; alignment, ownership and peer typography failures are also nonzero.
- Exit **2**: malformed, inconsistent, ambiguous or stale observations. No partial pass is returned.
- Exit **3**: no measured failure, but measurements or review remain unresolved. Do not promote this to pass.

The dependency-free validator enforces the local JSON schema and additional cross-record invariants. It uses explicit validation, not Python assertions. Duplicate keys/IDs, missing references, cycles, mismatched peer definitions, unsupported fields, nonfinite numbers, out-of-range geometry and stale hashes are rejected in normal and optimized Python.

## Observation contract

[`figure_observations.schema.json`](../scripts/figure_quality/figure_observations.schema.json) is the authoritative field/type contract. Unknown measurements use explicit `null`, not fabricated zero values or a checked flag. All root and element fields are required so omissions cannot quietly look like passes. `test_figure_quality_check.py:base_document` is a small complete synthetic example, not a real figure record or a universal style preset.

**Coordinate system.** `canvas.width_pt/height_pt` is the known intended final size. All bbox arrays are `[x,y,width,height]` normalized by the full canvas width/height, with top-left origin and positive visible extents. Individual components are bounded to `[-1,2]` to allow clipped/off-canvas content without accepting arbitrary coordinates. A zero-height stroke must include its actual visible thickness. Bounding boxes represent the *full unclipped* transformed element extent, not just surviving pixels. `clip_bbox` is an optional actual clip aperture. Without complete source content bounds, clipping remains unknown; do not use a clipped screenshot's surviving box to claim no clipping.

`bbox_basis` distinguishes verified `ink`, `stroke_outer` or `image_edge` from `container` and `unknown`. An Inkscape query or a text box is not automatically a glyph ink or baseline measurement. Container bounds cannot certify ownership or content visibility. `source_bbox` retains the measured original placement; it does not, by itself, authenticate source membership or prove a full transform chain.

**Identity and inventory.** Define the review unit from the intact source and the currently authorized panel selection, recorded in a separate trusted manifest. A source PPT may contain other unselected panels; record their exclusion there and preserve the original source. This checker does not authenticate selection authorization. Within the selected review unit, include every source-visible member and all required labels, legends, insets, scale bars and other accessories; neither omitting a row nor falsifying `source_present:false` may hide missing content. Every included source-visible member has a stable ID, source and final semantic parent, kind, role, and `source_present/present`. Include removed members with `present:false`; missing source rows cannot be detected by this checker. Removal and changed semantic parent are protected failures. Native group proximity is not scientific membership. A visible letter, legend, ROI, scale bar or connector needs its own evidence. `coverage.x/y` records measured, unmeasured, or reasoned nonapplicability. It does not assert that unlike data points must align. Completeness of this inventory requires independent source review.

**Transforms.** `[a,b,c,d,tx,ty]` maps source physical points to final physical points as `x'=a*x+c*y+tx`, `y'=b*x+d*y+ty`. It is the complete effective source-to-final transform, not the last SVG/PPT group alone. The list `allowed` declares permitted operation types for this observed task; it is not authenticated authorization. Operation classification uses a QR convention (rotation of the source x axis, axis scales, x shear, reflection) and a small numerical epsilon; visual anisotropy instead uses singular values and the recorded task tolerance. Text and measured geometry are checked using singular values even when anisotropic transforms are declared allowed. Deliberate rotation is not anisotropic distortion. Singular transforms fail. A different supported route is needed for unmodeled perspective or nonlinear mapping.

**Glyphs.** `glyph.ink_height_pt` is actual final-size glyph ink height measured in a renderer mask, verified glyph outline or manual source review. Do not substitute nominal point size, `em`, line box height or unrelated strings. A `peer_group` may contain only the same semantic role, comparison glyph/string, verified face and weight; mismatches are invalid instead of silently normalized. Use separate groups for intentional hierarchy, superscripts and unlike glyphs. Missing metrics stay unmeasured. Every real peer instance should be included. Comparing heights cannot by itself establish legibility, contrast or font correctness.

**Required semantic alignment.** Declare anchors independently with an exact element ID, axis, kind, basis, measured position and evidence. Actual baselines use `kind=basis=baseline`; equal text tops never substitute for them. Group outer bounds are supported explicitly; a group container must not be presented as an individual plot frame. Each `alignment_checks` row lists anchor IDs and expected offsets from its first anchor (whose target offset is zero), plus a tolerance fixed before reviewing the candidate. Check both left/right or top/bottom edges when the design requires both. No alignment exemption field exists: a violated declared requirement cannot silently become intentional. Changing requirements needs separately verified current user authorization and a fresh bound record. `peer_layout` cannot equalize data-coordinate elements; a verified own-axis/data attachment uses `scientific_attachment`. Missing observations remain unmeasured. An empty constraint set cannot claim alignment passed.

**Ownership.** A label's own frame/image and neighboring frames are source-verified references. The checker measures ink-to-frame minimum distance in final points, testing the declared maximum owner gap and required distance advantage over neighbors. This can flag detached/ambiguous positions; it does not understand reader perception or authorize reassigning a label. Review the full figure independently.

**Collisions.** Only text-involving collision pairs are in scope. Non-text occlusion, such as a colorbar over a map or an inset over data, requires separate verified mask/source review and is not silently certified by this tool. Text versus other visible objects produces bbox candidates. A frame's rectangular envelope often encloses empty space: overlap of envelopes is never proof of colliding ink. Without reliable intersection observations, a candidate is `review_needed`. `bbox_only` requires `intersects:null`. A supplied glyph-contour, rendered-mask, source-geometry or manually verified intersection can confirm/clear it, with an evidence reference. An intentional overlap can be reported `exempt` only with separate evidence supporting the intended relationship and preserved scientific visibility. Existing in the source is not sufficient: a deliberately included inset can still hide its parent curve. An exemption is not authorization to cover data or waive required alignment. This tool checks observed intersections, not near-miss visual clearance or z-order semantics. State unmeasured clearance separately in the task review.

**Scientific invariants.** `scientific_ratio` compares original and final *physical* meaningful aspect ratios, not normalized widths divided by heights on a nonsquare canvas. A measured image must provide this observation. Scale-bar records compare bar length divided by the same dimension of its own image and preserve stated value/unit; both source and final crop/calibration must have been verified independently. Data/axes/text/content/association fingerprints hash a specified canonical semantic payload, excluding only the separately authorized appearance fields. Document that payload in the evidence. They do not hash a whole changing SVG/PPT and call it semantic equality. Required fingerprints: text→text; axis/tick→axes; curve/marker→data; image/ROI→content; connector/scale bar→association. Missing or unreadable payloads remain unmeasured. This check has no route to waive protected data/text mutations as appearance work.

**Logical selection.** `expected_ids` is the source-verified complete semantic unit and `selected_ids` is the actual selected set. The checker also checks all inventoried source descendants; omitting an accessory from both lists cannot hide a missing selection. Connector endpoints remain separately associated, not automatically part of a rigid selection; include a connector only where its verified selection semantics require it. A declared selection does not prove the editor executed that selection or moved its contents safely.

**Thresholds and evidence.** Set thresholds from final size, measured uncertainty, accepted peers and task requirements *before* viewing the candidate. The schema ranges are numerical sanity bounds, not recommended style values. Preserve supporting render crops, native readback or extraction records outside reusable skill resources. Evidence strings describe or locate those records; they do not authenticate them. Do not copy private project observations into the generic fixture corpus.

## Coverage limits

A passing supplied record cannot establish that the source inventory was complete, observations were truthful, data payload canonicalization was correct, full-view readability was adequate, all legend/curve associations were understood, mandatory guide grouping was reversible, or PowerPoint/Origin reopened and refreshed successfully. Those remain separate acceptance gates. This utility does not invoke Origin, a bridge, a VM, a browser, deployment, publication, or source writing.

## Composite markers and directional ink-gap regressions

The version-1 schema already expresses these cases. The regression addition does not introduce an ellipse recognizer, a gap estimator, or a new source writer.

**Marker semantics precede primitive tags.** Identify marker constituents from the intact source and scientific association, including paths, circles, ellipses, fills with `stroke:none`, rims, shadows and highlights. Do not use `path` or visible stroke as the membership filter. Each actual visible marker layer uses `kind:marker`, regardless of whether its location uses `coordinate_space:data`. A non-rendering logical container may use `kind:object` with a descriptive role and complete semantic children. Container geometry is not a substitute for observing every visible layer.

The checker now tests source-verified marker-layer anisotropy as well as text and measurement geometry. Supply the *complete composed source-to-final linear transform of each visible layer*, including all ancestors and local compensation. Looking only at the outer plot transform falsely flags a successfully compensated marker; looking only at local compensation misses inherited distortion. The marker's data position can follow its verified plot mapping while the marker's local visible shape retains its source geometry. `allowed` does not waive a failed shape-preservation check.

Treat a real scientific region ellipse separately: for example `kind:region_stroke`, `coordinate_space:data`, with its verified complete mapping and protected data/association fingerprints. Its apparent axes may change under an intentional nonuniform plot/data transform. It must not be reclassified as a marker or forced circular merely because its primitive is an ellipse. Preserve deliberate elliptical marker/highlight shapes too: the check compares the source-to-final transform, not a rule that final width must equal height. If role or transform is unknown, record it as unknown instead of inventing a classification.

**Shape and layer centers are independent.** A marker can have undistorted layers and still be damaged by compensating each one around a different center. Use existing `center_x` and `center_y` anchors with `relationship:scientific_attachment` to compare all source-verified constituent centers or attachment points. The `target_offsets_pt` must reflect the source and intended final uniform scale/rotation. Preserve deliberately offset highlights and shadows; do not make every layer concentric. The checker now includes `observed_offsets_pt` alongside targets/residuals in alignment diagnostics, so a shape pass cannot hide a signed-offset failure. Existing membership and logical-selection checks cover only inventoried constituents. An entirely omitted layer or missing center constraint is not magically discovered.

**Measure horizontal and vertical ink clearance independently.** For each relevant pair, observe the actual final glyph/stroke boundary, not the text box, frame container, nominal font size, or a common frame gap. Existing scalar anchors can express a horizontal ink-right → next ink-left relation, or vertical ink-bottom → next ink-top relation. Use `basis:ink` or a genuinely observed `stroke_outer` as appropriate; missing ink positions remain `null`. `target_offsets_pt:[0,gap]` and that relation's `tolerance_pt` define a task-specific permitted interval. Include both directions and distinguish within-panel label/axis spacing from between-panel spacing where the figure's hierarchy needs it.

The gap target and tolerance must be chosen in advance from the accepted layout, actual glyph shapes, final viewing size and measurement uncertainty. A well-supported small optical difference between, for example, a protruding glyph and a square glyph can use a different target or tolerance. The checker does not demand universal exact equality, infer perceptual hierarchy, or widen tolerances after seeing an error. Different gaps are not automatically defects; equal frame gaps are not proof that any ink-clearance requirement passed.

Scalar offsets certify only the specifically measured directional relation. They are not a general nearest-contour distance engine. For rotated/curved shapes, oblique baselines, unsupported transforms, or uncertain facing boundaries, obtain real outline/mask/manual evidence for the chosen direction or leave the relation unmeasured. Full-size visual readability, perceived spacing, source classification, inventory completeness, center-association correctness and actual render extraction still require separate verification.

`test_marker_spacing_regressions.py` generates analytic synthetic SVGs and explicit observations for both topics. The observations derive from known geometry and are not extracted by an image recognizer. Tests include all-ellipse composite markers, fill-only highlights, full-transform compensation, shape-preserving center drift, intentionally offset/elliptical highlights, a preserved data-region ellipse, equal-frame/unequal-ink gaps in both directions, optical tolerances, missing measurements and CLI failures in normal/optimized Python.
