# Changelog

## 0.2.0 - 2026-11-08

- Adds a bounded, read-only checker for source-verified observations: final-size geometry, panel/annotation ownership, scientific fidelity, logical selection, marker transforms and directional ink spacing. This is not automatic image recognition.
- Adds independently generated synthetic fixtures and narrow source-existing occlusion evidence, with separate safe-inset controls. The original 12-case evaluation retains its initial error and correction: four clean controls and eight flawed cases. Source preservation alone does not establish visibility.
- Adds reviewed external-method references with explicit reuse and licensing boundaries; retains the existing source-edit and collaboration workflow.
- Release validation: 270 Python tests in normal mode and 270 in optimized mode (46 layout, 121 source-edit, 13 page preparation, 68 checker and 22 generated-corpus tests), plus nine Node interaction tests. Full-repository baseline: 1,072 passed executions and 406 expected external-fixture skips across normal/optimized modes.
- The synthetic corpus uses actual Inkscape SVG rendering. Generated cases, images, private ground truth and run reports are not distributed. The published skill contains 84 frozen generic source files plus release metadata.

No new native Origin writer, bridge, VM workflow, PowerPoint activation, or Origin edit/save/reopen acceptance is claimed. Human/source-verified observations, full-figure viewing and separate application checks remain necessary.

## 0.1.0 - 2026-11-08

First public release of the scientific-figure collaboration skill.

- Integrates interactive rough layout and existing-layout refinement with shared aesthetic, source-preservation, alignment and delivery gates.
- Includes offline interaction templates, bounded preview-edit helpers, generic optional online templates and native PPT guide add/inspect/restore support.
- Adds measured quality specifications and explicit communication guidance for unsupported source edits and application validation.
- Portable release validation: 180 Python tests in normal mode and 180 in optimized mode, plus nine Node interaction tests. Separate Inkscape smoke checks and LibreOffice guide-render checks were completed; guide removal restored exact PPT bytes and matched the clean render.

Guide support is limited to one selected simple figure slide without source groups or AlternateContent; no multi-figure guide chaining is claimed. Browser file-protocol behavior, actual PowerPoint activation and Origin edit/save/reopen were not validated by this release. Optional online deployment and its identity/storage bindings are not included.
